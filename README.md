# Frend

Голосовой и текстовый ассистент для Android. Модель (Groq) понимает просьбу и вызывает функции телефона.

## Что умеет

| Область | Функции |
|---|---|
| Будильник | ставит сразу, без подтверждения |
| Музыка | поиск и воспроизведение во встроенном плеере, пауза, дальше, назад, стоп, громкость, плейлисты |
| Заметки | создать, показать, найти, удалить |
| Фонарик | включить, выключить |
| Камера | открывает камеру в режиме фото или видео (затвор нажимает пользователь) |
| Скриншот | через службу специальных возможностей |
| Приложения | телефон (набор номера), камера, браузер, настройки, файлы, галерея, WhatsApp и любое установленное по названию |
| Браузер | открыть сайт, поиск в интернете |
| Настройки | открывает нужный раздел (Wi-Fi, Bluetooth, экран, звук и т.д.) |
| WhatsApp | чат с номером и готовым текстом (отправляет пользователь) |
| Фото, видео | поиск в галерее, открыть последнее |
| Файлы | поиск по памяти телефона, открыть найденный |

## Новое: контакты, напоминания, календарь, файлы, голос

| Область | Что умеет |
|---|---|
| Контакты | «позвони маме», «напиши Асель в WhatsApp, что буду через час», «какой номер у Ивана». Имена в любом падеже. Звонит сразу, если выдано разрешение на звонки, иначе открывает набор номера. Сообщение отправляет сам пользователь |
| Таймер | «таймер на 10 минут» (без модели) |
| Напоминания | «напомни через 2 часа позвонить в склад», «напомни завтра в 9 про отчёт». Приходят уведомлением и переживают перезагрузку |
| Календарь | «добавь в календарь встречу в пятницу в 10», «что у меня завтра» |
| Файлы | чтение xlsx и docx, объединение таблиц в один csv, конвертация xlsx в csv, кнопка 📎 в чате кладёт файл во Входящие |
| Фото | «распознай текст на картинке», «выпиши таблицу с фото в csv» (модель с поддержкой картинок Groq) |
| Голос | озвучка ответов (переключатель в меню чатов), плитка «Ассистент» в быстрых настройках, слово активации «Пятница» (меняется в настройках; распознаётся офлайн, см. раздел «Слово активации и слушание») |
| Память | длинные чаты автоматически сжимаются в краткую сводку, старые сообщения не отправляются в модель целиком |

## Интернет, сводки, шторка и яркость

| Область | Что умеет |
|---|---|
| Интернет | «какая погода в Астане», «какой курс доллара», «какие новости», «найди в интернете …». Поиск делает модель gpt-oss на Groq (встроенный browser_search, тот же ключ) и называет источники. «Найди в браузере …» по-прежнему открывает браузер |
| Автообновление | «присылай каждое утро в 8 курс доллара и погоду»: в это время ассистент сам ищет и присылает уведомлением. Список: «какие у меня сводки», отмена: «отмени сводку про курс» |
| Шторка | «включи/выключи вайфай, блютуз, мобильный интернет, режим полёта, геолокацию, точку доступа, NFC, не беспокоить, экономию заряда, тёмную тему» и любая плитка по названию. Нажимает плитку через службу специальных возможностей |
| Автоповорот, яркость | «яркость на 50», «сделай ярче», «автояркость», «выключи автоповорот». Нужно разрешение «Изменение системных настроек» (приложение само откроет экран) |

Для переключателей шторки после обновления нужно выключить и снова включить службу «Assistant» в специальных возможностях: ей нужны новые права.

## Подтверждения

Ассистент сам спрашивает «да или нет» перед опасным: удаление заметок, плейлистов, напоминаний и сводок, перезапись или дописывание файла в `Исходящих`, звонок контакту. Выполняет только после «да», вопрос живёт 5 минут. Файлы во `Входящих` он не меняет и не удаляет вообще, приложения удалять и менять не умеет. Безобидное (музыка, фонарик, яркость, будильник) делает сразу.

## Как экономятся токены

1. **Без модели (0 токенов).** Типовые команды разбирает код (`LocalCommands`): будильник, фонарик, громкость, пауза и переключение, «включи музыку/песню/плейлист», открыть приложение, сайт, настройки, набрать номер, заметка, время и дата. Также выученные фразы и «включи <исполнитель>», если он есть в музыке телефона.
2. **Короткий запрос к модели.** Если правила не поняли: в модель уходят только нужные группы функций, последние 8 сообщений, низкая глубина рассуждения, а результат действия показывается как есть, без второго вызова.
3. **Беседа.** Для обычных вопросов: сжатый список функций и последние 24 сообщения.

Составные просьбы («включи фонарик и поставь будильник») всегда идут в модель.

## Музыка

Ассистент загружает всю музыку телефона в память и ищет по части названия, исполнителю, альбому, русскими буквами по английским названиям («линкин парк» найдёт Linkin Park) и с небольшими опечатками. Файлы, которые система ещё не знает (скачанное, из мессенджеров), добавляются в медиатеку автоматически (нужен доступ «Все файлы»).

## Общая папка и чаты

В памяти телефона создаётся открытая папка `Assistant` (видна в файловом менеджере и по USB, нужен доступ «Все файлы»):

- `Входящие` — клади сюда файлы и базы данных. Ассистент читает текстовые файлы (txt, csv, json и др.), ищет в них строки, смотрит таблицы и делает запросы SELECT к базам sqlite (только чтение). Новые файлы он замечает сам при открытии приложения. Ничего не меняет и не удаляет.
- `Исходящие` — сюда ассистент сохраняет файлы, которые создаёт сам.

Чаты как в ChatGPT: боковое меню со списком, «Новый чат», долгое нажатие на чат — удалить. Название берётся из первого сообщения. Старая переписка стала первым чатом.

## Фоновая работа

Постоянное уведомление в шторке с кнопками «Говорить», «Чат» и «Выкл». «Говорить» запускает голосовую команду без открытия приложения, ответ показывается в шторке. Возвращается после перезагрузки (на Xiaomi нужно разрешить автозапуск приложения). «Выкл» останавливает службу до следующего открытия приложения.

## Разрешения, которые нужно выдать вручную

1. **Фото, видео, музыка, уведомления** — спросит приложение при запуске.
2. **Все файлы** (для поиска файлов) — спросит само, когда понадобится: откроет настройки, включить переключатель для Assistant.
3. **Скриншоты** — Настройки → Специальные возможности → Assistant → включить. Если пункт серый (приложение не из магазина): Настройки → Приложения → Assistant → меню ⋮ → «Разрешить ограниченные настройки».

## Известные ограничения

- Камера, звонок и отправка сообщения WhatsApp запускаются пользователем на экране, Android не даёт приложению нажимать за него.
- Wi-Fi, Bluetooth, режим полёта и т.п. программно переключать нельзя, ассистент открывает нужный экран настроек.
- Скриншот пока делается после сворачивания ассистента на рабочий стол.
- Фонарик гаснет, если камеру открывает другое приложение.
- Плейлисты хранятся в файле `playlists.json` во внутренней памяти приложения.

## Тесты

Разбор команд, транслит и поиск музыки покрыты юнит-тестами (`app/src/test`), они запускаются в GitHub Actions перед сборкой APK.

## Сборка

GitHub Actions (`Build APK`): запускается при пуше в `main` и вручную (Actions → Build APK → Run workflow, можно выбрать ветку). Готовый файл — в разделе Artifacts запуска. Ключ Groq берётся из секрета `GROQ_API_KEY`.

## Музыка: разметка и второе приложение «Музыка»

- **Разметка.** Скажи «проанализируй мою музыку» (или кнопка «Разметить» в приложении «Музыка»). Модель определяет жанр, настроение (энергичная, спокойная, весёлая, грустная, романтичная, танцевальная, для фона, мощная) и энергичность 1–5 для каждой песни; жанр из тегов файла подсказывается модели. Идёт в фоне, прогресс в уведомлении, теги хранятся в `music_tags.json`.
- **По голосу.** «Включи спокойную музыку», «поставь что-нибудь энергичное», «музыку для работы», «включи рок/джаз/рэп», «как идёт разметка», «выгрузи список песен» (CSV `songs.csv` в Исходящие: исполнитель, название, альбом, жанр, настроение, энергия).
- **Приложение «Музыка»** — отдельный значок на экране. Вкладки: Треки, Настроение, Жанры, Исполнители, Плейлисты; поиск, мини-плеер, полноэкранный плеер (обложка, перемотка, перемешивание, повтор, очередь, «Ещё такое», таймер сна), меню песни (следующей, в очередь, в плейлист, характеристики). «Открой музыку» в ассистенте открывает его.

### Музыка, часть 2: разметка сама, таблица, лайки, папки

- **Таблица `Assistant/Музыка.xlsx`.** Приложение создаёт её само и обновляет при каждой разметке: исполнитель, название, альбом, жанр, настроение, энергичность, темп, описание, уверенность, пометка, «Нравится», «Папки», «Источник». Она переживает переустановку: при первом запуске «Музыка» читает её и размечает только то, чего там нет. Правки в Excel подхватываются при запуске. Свою готовую таблицу (например, `songs_by_mood.xlsx`) можно положить во «Входящие» и сказать «импортируй таблицу музыки».
- **Разметка сама.** При первом открытии «Музыки» (и после переустановки) в фоне идёт разметка пачками через модель Groq. Поиск в интернете не используется, чтобы не тратить дневной лимит. Если лимит кончился, разметка останавливается и продолжится позже. Ход виден в уведомлении, в конце приходит уведомление «Музыка размечена».
- **Разметка через другой ИИ.** Меню ⋮ → «Подготовить для другого ИИ» (или «подготовь музыку для другого ИИ») создаёт в `Исходящие/Музыка для ИИ` файлы-части по 100 песен с готовой инструкцией. Скопируй часть в ChatGPT, Gemini или Claude, скопируй его ответ и в «Музыке» нажми ⋮ → «Вставить ответ другого ИИ» (понимает CSV и таблицы markdown). Либо сохрани ответ как csv во «Входящие» и скажи «импортируй таблицу музыки».
- **Лайки.** ♥ в плеере, в меню песни и в редакторе; «поставь лайк», «не нравится эта песня», «включи любимое». Дизлайкнутые песни не попадают в подборки.
- **Редактор характеристик** (меню песни → «Изменить характеристики»): настроения галочками (можно несколько), жанр, энергичность 1–5, темп, описание, папки. Ручные правки ИИ больше не перезаписывает. Голосом: «эта песня грустная».
- **Папки** («Для бега», «Для прогулки») и плейлисты — одно и то же: создавать, переименовывать, удалять, добавлять и убирать песни, перекладывать между папками, в том числе голосом («убери эту песню из бега и добавь в прогулку»).
- **Сортировка:** по названию, исполнителю, дате добавления (новые/старые), любимые сверху.

## Дизайн, голос и надёжность (ветка polish)
- Чат: светлая/тёмная тема по системе, пузыри, анимация «думает», блоки кода с кнопкой «Копировать», копирование сообщений, подсказки в пустом чате.
- Озвучка: выбор голоса и скорости (меню чатов → «Голос и скорость озвучки»), паузы в речи, код не зачитывается.
- Голосовой ввод: ждёт паузу 1,8 с, перед записью останавливает озвучку.
- Wi-Fi/Bluetooth/режим полёта/геолокация/экономия заряда: состояние берётся из системы, после нажатия проверяется результат, при неудаче нажатие повторяется.

## Универсальность и музыка (ветка polish)
- В коде нет личных данных: имя и город приложение запоминает по просьбе («мой город — Астана», «меня зовут Анна»), язык, страна, валюта, единицы, 12/24 часа, модель телефона и доступные функции определяются само.
- Погода берётся из Open-Meteo без ИИ; без заданного города город угадывается по часовому поясу с предупреждением.
- Импорт разметки от другого ИИ: xlsx (все листы), csv, tsv, txt, md; заголовки по-русски и по-английски; «Исполнитель - Песня» в одной колонке; нечёткое сопоставление названий; можно выбрать файл в «Музыке» (⋮ → «Выбрать файл с разметкой»).
- Повторная разметка: «разметь музыку заново», «повтори неопознанные»; ручные правки и оценки сохраняются.
- Сердечко в уведомлении плеера, новый дизайн «Музыки».

## Состояние телефона и приватность (ветка device-info)

Ассистент отвечает без модели (быстро и бесплатно по лимиту) на вопросы: «сколько заряда», «какая сеть», «сколько оперативной памяти», «сколько свободной памяти», «что занимает память», «какие приложения занимают место», «какими приложениями больше пользуюсь», «какое состояние телефона». Для списков приложений нужен «Доступ к истории использования» (откроется сам при первом вопросе).

«Что на экране?»: чтение экрана выключено по умолчанию. Включается в меню «Что ассистент может видеть», работает только по просьбе, пароли не читаются.

Подготовлено под Shizuku (процессы и память по приложениям): `ShellBackend.kt`. Подключение и дальнейшие задачи: `docs/TZ_DEVICE_INFO.md`.

## Слово активации и слушание (версии 1.29–1.39)

- **Слово активации** — «Пятница» по умолчанию, меняется в Настройках. Распознавание полностью офлайн (Sherpa-ONNX, русская модель T-One вшита в APK, интернет для слова не нужен). Работает в фоне с уведомлением «Пауза / Отмена / Выкл».
- **Как говорить:** «Пятница, поставь будильник на семь» одной фразой или «Пятница» → сигнал → команда в течение «Времени на команду».
- **Пауза посреди фразы (1.39):** если команда оборвалась («Пятница, поставь…» — пауза — «…будильник на семь»), ассистент ждёт продолжение 3,5 с и склеивает куски. Законченная команда выполняется сразу.
- **Ошибки распознавания (1.39):** если правила не поняли фразу, она проверяется ещё раз с исправленными словами («включите фанарик» → фонарик). Звонки, заметки и профиль по угаданной фразе не выполняются — их разбирает модель. Голосовые запросы модель получает с пометкой, что слова могли исказиться.
- **Ответ «да/нет»** на вопрос ассистента слушается без слова активации. Пока ассистент говорит, микрофон не слушает его голос.
- **Режим шёпота** (Настройки → Микрофон, по умолчанию вкл.): автоусиление тихой речи, системный шумоподавитель выключен. Если ложные срабатывания — выключить.
- **Журнал слушания** (Настройки): что услышал распознаватель и что сделал ассистент; «всё услышанное» пишется только по переключателю, хранится только на телефоне. Кнопка «Копировать» — чтобы прислать журнал для разбора ошибок.
- **Консоль (Shizuku)** — только чтение (процессы, память), белый список команд, кнопка «Проверить консоль» с причиной, если не работает.

## Версия 1.40: плеер Harmonia, «Моя волна», диалог с перебиванием

### Музыка — теперь как в Harmonia (репозиторий `music`, ветка `claude/music-flame-ui`)
- **Плеер перенесён целиком:** живой сине-фиолетовый фон в ритм, спектр, профиль настроения песни по фрагментам, эквалайзер и усиление баса, редактор обложек, починка «кракозябр» в названиях, выключение папок, журнал воспроизведения, пауза при отключении наушников. Настройки плеера — в «Музыке»: ⋮ → «Настройки» (отдельно от настроек ассистента).
- **Точная разметка в два этапа.** (1) Телефон сам слушает каждую песню: темп (BPM), энергия, танцевальность, позитивность, напряжение, мажор/минор и профиль настроений в процентах, в том числе смена настроения внутри песни. (2) Модель Groq по названию и исполнителю уточняет жанр и «характер», который по звуку не слышно (романтичная, грустная по тексту). Результаты сводятся (`MoodFusion`): темп и энергия — по звуку, жанр — от модели, настроение — смесь, вес модели зависит от её уверенности. Старая разметка Frend не выбрасывается: песни один раз дослушиваются и сводятся с ней. Ручные правки не трогаются.
- **Для тебя** (вкладка «Подборки»):
  - **Моя волна** — бесконечная, под твой вкус. Вкус считается по лайкам, дослушанным и пропущенным песням (свежие весят больше). Внутри волны пропуск сразу уводит от похожих песен, дослушанная — притягивает. Один исполнитель не подряд, только что звучавшее не повторяется.
  - **Волна по настроению**, **Под это время** (утро, работа, вечер, сон), **Открытия** (не слушал, но подойдёт), **Забытое любимое**, **Чаще всего**, **Мой вкус**.
  - **Умные подборки:** утро, фокус, тренировка, бег (150–180 шагов), танцы, в дорогу, вечер, сон, романтика, погрустить, мощь, и своя по настроению, энергии и BPM.
  - В плеере: **«Ещё такое»** — волна похожих по звуку, жанру и исполнителю (не прерывая песню), **«Не нравится — дальше»**.
- **Голосом (без модели, 0 токенов):** «включи мою волну», «включи что-нибудь похожее», «песни похожие на Believer», «музыку для бега / для сна / в дорогу», «включи волну спокойную», «что-нибудь под настроение», «не нравится, дальше», «что играет», «перемешай», «повтори эту песню», «перемотай назад на минуту», «таймер сна на 20 минут», «какой у меня музыкальный вкус». «Включи музыку» без уточнений теперь запускает «Мою волну» (когда музыка разобрана).
- Статистика прослушиваний хранится только на телефоне (`listen_stats.json`), стереть: «Мой вкус» → «Забыть статистику».

### Режим диалога и перебивание
- **Режим диалога** (Настройки → Диалог, по умолчанию вкл.): после ответа можно сразу говорить дальше без «Пятница» (окно 8 с, настраивается). Молчание или «хватит / всё, спасибо / пока» — конец.
- **Перебивание голосом:** микрофон слушает и пока ассистент говорит. Скажи «стоп», «подожди» или сразу новую просьбу — он замолчит и выслушает. Эхо самого ассистента отличается по словам (`BargeIn`): то, что он сейчас произносит, не считается. Лучше всего работает в наушниках; на громком динамике возможны ложные остановки — тогда выключи «Перебивать голосом».
- **Начать разговор:** «Пятница, давай поговорим» или долгое нажатие на микрофон в чате (работает, даже если фоновое слово выключено). Реплики сразу появляются в чате.

### Мелочи
- Калькулятор без модели: «сколько будет двадцать пять умножить на четыре», «15 процентов от 3000», «корень из 144».

## Версия 1.41: универсальный помощник

### Начать: одна кнопка
Настройки → **«Выдать все разрешения через Shizuku»**. Выдаёт этому приложению: микрофон, контакты, звонки, календарь, уведомления, медиа, Bluetooth, «Все файлы», историю использования, системные и защищённые настройки, «поверх окон», включает службу специальных возможностей и чтение уведомлений, снимает ограничения батареи (слово активации не засыпает). Голосом: «выдай все разрешения». После обновления приложения кнопку стоит нажать ещё раз. На Xiaomi автозапуск по-прежнему включается вручную.

### Меньше ложных срабатываний
- «в пятницу», «до пятницы», «эту пятницу» в речи и по телевизору больше не будят ассистента: обращение принимается в начале фразы («Пятница, …», «эй, Пятница»), в середине — только точное «Пятница» не после предлога.
- Окно после ответа (режим диалога) принимает только обращения: вопросы, просьбы, команды, «да/нет», «а завтра?». Чужой разговор, «ага», «угу» пропускаются (видно в «Журнале слушания»: «не похоже на обращение»).
- Пустое «Пятница, ну…» не уходит в модель, а ждёт команду.
- Перебивание на громком динамике — только стоп-словом («стоп», «подожди», «хватит») или словом активации; в наушниках — любой фразой.

### Управление телефоном
- **Переключатели через Shizuku напрямую** (без шторки, быстро и надёжно): Wi-Fi, Bluetooth, мобильный интернет, режим полёта, геолокация, «Не беспокоить», NFC. Без Shizuku — нажатием плитки, как раньше.
- **Экран голосом:** «на главный экран», «недавние», «открой шторку», «заблокируй экран», «раздели экран», «пролистай вниз/вверх», «нажми Отправить», «введи привет, как дела», «закрой приложение Ютуб» (Shizuku, с подтверждением). Модель тоже умеет это делать в составных просьбах.
- **Уведомления:** «что пришло», «прочитай уведомления», «что написали в Телеграме». Хранятся только в памяти.

### Живой экран и переводчик
- **«Включи живой экран»** (или Настройки → Экран): вопросы о том, что видно («что тут?», «помоги ответить на это сообщение», «что за ошибка», «реши эту задачу»), уходят модели вместе со снимком экрана (Android 11+), ответ — голосом и карточкой поверх экрана. У края экрана кнопки: **«?»** — заговорить про экран, **«Aあ»** — перевести. Кнопки перетаскиваются. «Выключи живой экран» — всё убирается.
- **Переводчик:** «переведи экран» / «переведи экран на английский» или «Aあ». Надписи переводятся прямо на своих местах; текст на картинках, в играх и видео — карточкой по снимку экрана. Касание убирает перевод, переход в другое приложение — тоже.
- «Что на экране» теперь смотрит снимок, а не только текст окна.

### Файлы — порядок без удаления
- «Разложи загрузки» (по типам: Документы, PDF, Таблицы, Картинки, Видео, Музыка, Архивы, Установщики, Книги…), «…по датам», «отсортируй документы», «разложи скриншоты по месяцам». Сначала план и вопрос «да/нет». Файлы только перемещаются внутри папки, одинаковые имена не перезаписываются («отчёт (2).pdf»), недокачанное и свежее не трогается, папки в `Android/` — никогда.
- «Верни файлы как было» — откат последней сортировки.
- «Какие файлы занимают место», «самые большие файлы», «найди дубликаты» — только отчёт, ничего не удаляется.

### Состояние телефона
- «Какой износ батареи» — ёмкость от заводской и число циклов (через Shizuku, если телефон отдаёт).
- «Полный отчёт о телефоне» — модель, Android, время без перезагрузки, батарея, износ, сеть, память, место, частые приложения.

### Что включить один раз вручную, если без Shizuku
Специальные возможности → Assistant (после обновления выключи и включи заново: добавились снимок экрана и жесты), Доступ к уведомлениям → Assistant, Все файлы → Assistant.

### Наглядные ответы
Ассистент дублирует главное картинкой прямо в чате: цветные столбцы и линии, круговые диаграммы, таблицы (числа по правому краю, полосатые строки), деревья с ветками, списки, шаги, план с галочками, временная шкала, полоски прогресса, плитки статистики и **рисунки фигурами** (прямоугольники, круги, линии, стрелки, подписи — как в Паскале). Рисует сам телефон, без интернета и библиотек; модель присылает только короткое описание (блок ```visual с JSON).
- Касание картинки — на весь экран; «Сохранить» — в Галерею (Pictures/Assistant); «Поделиться». Долгое нажатие — сразу сохранить.

### Мини-приложения
«Сделай калькулятор ипотеки», «тренажёр таблицы умножения», «тест по истории», «покажи, как падает мяч» — модель пишет маленькую страницу, в чате появляется кнопка **▶ Открыть**. Страница работает в песочнице: без интернета, без доступа к файлам и к телефону. «Сохранить» — в Исходящие/Мини-приложения; «мои мини-приложения», «открой мини-приложение калькулятор».

### Подсказки на экране
«Покажи, как включить NFC», «покажи, где отменить подписку», «научи меня делать скриншот»: ассистент смотрит на экран, затемняет всё лишнее, обводит нужную кнопку пульсирующей рамкой со стрелкой и говорит, что нажать. Нажал — следующий шаг (до 14). «Сделай сам» на карточке или голосом «сделай сам включи тёмную тему» — нажимает за тебя; удалить, оплатить, отправить, подтвердить — никогда, только ты. Нужно открыть другое приложение — откроет сам.

### План и цепочки действий
Сложные просьбы («найди номер Ивана и отправь его маме в WhatsApp», «проверь заряд, и если меньше 30 — включи экономию») модель выполняет по шагам: составляет план, вызывает функции одну за другой, видит результат каждой и в конце показывает план с галочками. Простые команды — как раньше, одним запросом.

### Учится работать без интернета
- Каждая команда, понятая через модель, запоминается: в следующий раз — без модели.
- **Шаблоны с числами:** выучил «громкость на 30» — понимает и «громкость на 70», «разбуди в 6 45».
- **Похожие фразы** с небольшими отличиями тоже узнаются.
- **Связки:** если для фразы понадобилось несколько действий — в следующий раз они выполняются сами.
- **Научи сам:** «когда я говорю „я дома“, включи вайфай и выключи мобильный интернет» — работает офлайн.
- «Чему ты научился» — таблица; «забудь фразу …», «забудь всё выученное». Настройки → «Выученные команды».

### Отчёт для разработчика
Настройки → «Отчёт для разработчика» или голосом: версия, Shizuku, службы, разрешения, переключатели, журнал слушания и действий. Копируется и открывается «Поделиться». Переписки, контакты и файлы не входят.

## Версия 1.46: офлайн-мозг и быстрые кнопки

### Понималка — команды своими словами, без интернета
«Вырубай инет», «ничего не слышно», «посвети», «звук на сорок» — понимаются без модели. Маленькая обучаемая модель (килобайты): сравнивает фразу с примерами по основам слов и кусочкам букв, поэтому прощает окончания и ошибки распознавания. Из коробки — около 70 команд и сотни вариантов (`assets/brain/intents.tsv`). Учится сама: на выученных командах и на вариантах, которые придумывает Groq (раз в 5 дней, «обучись» или Настройки → Офлайн-мозг → «Обучить понималку сейчас»; файл `Assistant/База/понималка.tsv` можно править).

### Навыки
Одна фраза — несколько действий. Готовые: «я дома» (Wi-Fi вкл, мобильный интернет выкл), «ухожу», «доброе утро» (отчёт о телефоне и уведомления), «спокойной ночи» (музыка стоп, «Не беспокоить», яркость 10), «кино», «тренировка», «за рулём», «экономия», «работа». Свои: «создай навык „дача“: выключи вайфай, включи мобильный интернет, яркость 80». «Мои навыки», «выключи навык кино». Файлы — `Assistant/Навыки/*.json`.

### База знаний
SQLite в `Assistant/База/знания.db`, работает без интернета. «Запомни факт: код домофона 4512» → «что ты знаешь про код домофона». «Собери справочник по первой помощи» — Groq соберёт записи, дальше они доступны офлайн. Подходящие записи подсказываются модели и в онлайне. Из коробки — справка по ассистенту и полезное (экстренные номера, первая помощь, батарея, память).

### Режим мозга
Настройки → Офлайн-мозг: **Авто** (онлайн; без сети — понималка, навыки, база), **Только онлайн**, **Только офлайн**. Без интернета ассистент больше не говорит просто «ошибка», а делает то, что умеет офлайн.

### Быстрые кнопки экрана
- **Шторка:** в уведомлении ассистента — «Перевести» и «Экран»; плитки «Перевести экран», «Что на экране», «Живой экран» (добавь их, изменив набор плиток).
- **Чат:** над полем ввода — «Перевести экран», «Что на экране», «Живой экран: вкл/выкл». Чат сворачивается, и действие выполняется над приложением под ним.
