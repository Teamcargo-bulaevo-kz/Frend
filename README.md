# Frend

Голосовой и текстовый ассистент для Android. Модель (Groq) понимает просьбу и вызывает функции телефона.

## Что умеет

| Область | Функции |
|---|---|
| Будильник | ставит сразу, без подтверждения |
| Музыка | поиск и воспроизведение во встроенном плеере, пауза, дальше, назад, стоп, громкость, плейлисты |
| Заметки | создать, показать, найти, удалить |
| Фонарик | включить, выключить |
| Камера | открывает камеру в режиме фото или видео (затвор нажимает пользователь) |
| Скриншот | через службу специальных возможностей |
| Приложения | телефон (набор номера), камера, браузер, настройки, файлы, галерея, WhatsApp и любое установленное по названию |
| Браузер | открыть сайт, поиск в интернете |
| Настройки | открывает нужный раздел (Wi-Fi, Bluetooth, экран, звук и т.д.) |
| WhatsApp | чат с номером и готовым текстом (отправляет пользователь) |
| Фото, видео | поиск в галерее, открыть последнее |
| Файлы | поиск по памяти телефона, открыть найденный |

## Как экономятся токены

1. **Без модели (0 токенов).** Типовые команды разбирает код (`LocalCommands`): будильник, фонарик, громкость, пауза и переключение, «включи музыку/песню/плейлист», открыть приложение, сайт, настройки, набрать номер, заметка, время и дата. Также выученные фразы и «включи <исполнитель>», если он есть в музыке телефона.
2. **Короткий запрос к модели.** Если правила не поняли: в модель уходят только нужные группы функций, последние 8 сообщений, низкая глубина рассуждения, а результат действия показывается как есть, без второго вызова.
3. **Беседа.** Для обычных вопросов: сжатый список функций и последние 24 сообщения.

Составные просьбы («включи фонарик и поставь будильник») всегда идут в модель.

## Музыка

Ассистент загружает всю музыку телефона в память и ищет по части названия, исполнителю, альбому, русскими буквами по английским названиям («линкин парк» найдёт Linkin Park) и с небольшими опечатками. Файлы, которые система ещё не знает (скачанное, из мессенджеров), добавляются в медиатеку автоматически (нужен доступ «Все файлы»).

## Фоновая работа

Постоянное уведомление в шторке с кнопками «Говорить», «Чат» и «Выкл». «Говорить» запускает голосовую команду без открытия приложения, ответ показывается в шторке. Возвращается после перезагрузки (на Xiaomi нужно разрешить автозапуск приложения). «Выкл» останавливает службу до следующего открытия приложения.

## Разрешения, которые нужно выдать вручную

1. **Фото, видео, музыка, уведомления** — спросит приложение при запуске.
2. **Все файлы** (для поиска файлов) — спросит само, когда понадобится: откроет настройки, включить переключатель для Assistant.
3. **Скриншоты** — Настройки → Специальные возможности → Assistant → включить. Если пункт серый (приложение не из магазина): Настройки → Приложения → Assistant → меню ⋮ → «Разрешить ограниченные настройки».

## Известные ограничения

- Камера, звонок и отправка сообщения WhatsApp запускаются пользователем на экране, Android не даёт приложению нажимать за него.
- Wi-Fi, Bluetooth, режим полёта и т.п. программно переключать нельзя, ассистент открывает нужный экран настроек.
- Скриншот пока делается после сворачивания ассистента на рабочий стол.
- Фонарик гаснет, если камеру открывает другое приложение.
- Плейлисты хранятся в файле `playlists.json` во внутренней памяти приложения.

## Тесты

Разбор команд, транслит и поиск музыки покрыты юнит-тестами (`app/src/test`), они запускаются в GitHub Actions перед сборкой APK.

## Сборка

GitHub Actions (`Build APK`): запускается при пуше в `main` и вручную (Actions → Build APK → Run workflow, можно выбрать ветку). Готовый файл — в разделе Artifacts запуска. Ключ Groq берётся из секрета `GROQ_API_KEY`.
