# Frend

Голосовой и текстовый ассистент для Android. Модель (Groq) понимает просьбу и вызывает функции телефона.

## Что умеет

| Область | Функции |
|---|---|
| Будильник | ставит сразу, без подтверждения |
| Музыка | поиск и воспроизведение во встроенном плеере, пауза, дальше, назад, стоп, громкость, плейлисты |
| Заметки | создать, показать, найти, удалить |
| Фонарик | включить, выключить |
| Камера | открывает камеру в режиме фото или видео (затвор нажимает пользователь) |
| Скриншот | через службу специальных возможностей |
| Приложения | телефон (набор номера), камера, браузер, настройки, файлы, галерея, WhatsApp и любое установленное по названию |
| Браузер | открыть сайт, поиск в интернете |
| Настройки | открывает нужный раздел (Wi-Fi, Bluetooth, экран, звук и т.д.) |
| WhatsApp | чат с номером и готовым текстом (отправляет пользователь) |
| Фото, видео | поиск в галерее, открыть последнее |
| Файлы | поиск по памяти телефона, открыть найденный |

## Новое: контакты, напоминания, календарь, файлы, голос

| Область | Что умеет |
|---|---|
| Контакты | «позвони маме», «напиши Асель в WhatsApp, что буду через час», «какой номер у Ивана». Имена в любом падеже. Звонит сразу, если выдано разрешение на звонки, иначе открывает набор номера. Сообщение отправляет сам пользователь |
| Таймер | «таймер на 10 минут» (без модели) |
| Напоминания | «напомни через 2 часа позвонить в склад», «напомни завтра в 9 про отчёт». Приходят уведомлением и переживают перезагрузку |
| Календарь | «добавь в календарь встречу в пятницу в 10», «что у меня завтра» |
| Файлы | чтение xlsx и docx, объединение таблиц в один csv, конвертация xlsx в csv, кнопка 📎 в чате кладёт файл во Входящие |
| Фото | «распознай текст на картинке», «выпиши таблицу с фото в csv» (модель с поддержкой картинок Groq) |
| Голос | озвучка ответов (переключатель в меню чатов), плитка «Ассистент» в быстрых настройках, слово «Джарвис» (переключатель в меню, нужен открытый интернет и тратит заряд; включается только из открытого приложения) |
| Память | длинные чаты автоматически сжимаются в краткую сводку, старые сообщения не отправляются в модель целиком |

## Интернет, сводки, шторка и яркость

| Область | Что умеет |
|---|---|
| Интернет | «какая погода в Астане», «какой курс доллара», «какие новости», «найди в интернете …». Поиск делает модель gpt-oss на Groq (встроенный browser_search, тот же ключ) и называет источники. «Найди в браузере …» по-прежнему открывает браузер |
| Автообновление | «присылай каждое утро в 8 курс доллара и погоду»: в это время ассистент сам ищет и присылает уведомлением. Список: «какие у меня сводки», отмена: «отмени сводку про курс» |
| Шторка | «включи/выключи вайфай, блютуз, мобильный интернет, режим полёта, геолокацию, точку доступа, NFC, не беспокоить, экономию заряда, тёмную тему» и любая плитка по названию. Нажимает плитку через службу специальных возможностей |
| Автоповорот, яркость | «яркость на 50», «сделай ярче», «автояркость», «выключи автоповорот». Нужно разрешение «Изменение системных настроек» (приложение само откроет экран) |

Для переключателей шторки после обновления нужно выключить и снова включить службу «Assistant» в специальных возможностях: ей нужны новые права.

## Подтверждения

Ассистент сам спрашивает «да или нет» перед опасным: удаление заметок, плейлистов, напоминаний и сводок, перезапись или дописывание файла в `Исходящих`, звонок контакту. Выполняет только после «да», вопрос живёт 5 минут. Файлы во `Входящих` он не меняет и не удаляет вообще, приложения удалять и менять не умеет. Безобидное (музыка, фонарик, яркость, будильник) делает сразу.

## Как экономятся токены

1. **Без модели (0 токенов).** Типовые команды разбирает код (`LocalCommands`): будильник, фонарик, громкость, пауза и переключение, «включи музыку/песню/плейлист», открыть приложение, сайт, настройки, набрать номер, заметка, время и дата. Также выученные фразы и «включи <исполнитель>», если он есть в музыке телефона.
2. **Короткий запрос к модели.** Если правила не поняли: в модель уходят только нужные группы функций, последние 8 сообщений, низкая глубина рассуждения, а результат действия показывается как есть, без второго вызова.
3. **Беседа.** Для обычных вопросов: сжатый список функций и последние 24 сообщения.

Составные просьбы («включи фонарик и поставь будильник») всегда идут в модель.

## Музыка

Ассистент загружает всю музыку телефона в память и ищет по части названия, исполнителю, альбому, русскими буквами по английским названиям («линкин парк» найдёт Linkin Park) и с небольшими опечатками. Файлы, которые система ещё не знает (скачанное, из мессенджеров), добавляются в медиатеку автоматически (нужен доступ «Все файлы»).

## Общая папка и чаты

В памяти телефона создаётся открытая папка `Assistant` (видна в файловом менеджере и по USB, нужен доступ «Все файлы»):

- `Входящие` — клади сюда файлы и базы данных. Ассистент читает текстовые файлы (txt, csv, json и др.), ищет в них строки, смотрит таблицы и делает запросы SELECT к базам sqlite (только чтение). Новые файлы он замечает сам при открытии приложения. Ничего не меняет и не удаляет.
- `Исходящие` — сюда ассистент сохраняет файлы, которые создаёт сам.

Чаты как в ChatGPT: боковое меню со списком, «Новый чат», долгое нажатие на чат — удалить. Название берётся из первого сообщения. Старая переписка стала первым чатом.

## Фоновая работа

Постоянное уведомление в шторке с кнопками «Говорить», «Чат» и «Выкл». «Говорить» запускает голосовую команду без открытия приложения, ответ показывается в шторке. Возвращается после перезагрузки (на Xiaomi нужно разрешить автозапуск приложения). «Выкл» останавливает службу до следующего открытия приложения.

## Разрешения, которые нужно выдать вручную

1. **Фото, видео, музыка, уведомления** — спросит приложение при запуске.
2. **Все файлы** (для поиска файлов) — спросит само, когда понадобится: откроет настройки, включить переключатель для Assistant.
3. **Скриншоты** — Настройки → Специальные возможности → Assistant → включить. Если пункт серый (приложение не из магазина): Настройки → Приложения → Assistant → меню ⋮ → «Разрешить ограниченные настройки».

## Известные ограничения

- Камера, звонок и отправка сообщения WhatsApp запускаются пользователем на экране, Android не даёт приложению нажимать за него.
- Wi-Fi, Bluetooth, режим полёта и т.п. программно переключать нельзя, ассистент открывает нужный экран настроек.
- Скриншот пока делается после сворачивания ассистента на рабочий стол.
- Фонарик гаснет, если камеру открывает другое приложение.
- Плейлисты хранятся в файле `playlists.json` во внутренней памяти приложения.

## Тесты

Разбор команд, транслит и поиск музыки покрыты юнит-тестами (`app/src/test`), они запускаются в GitHub Actions перед сборкой APK.

## Сборка

GitHub Actions (`Build APK`): запускается при пуше в `main` и вручную (Actions → Build APK → Run workflow, можно выбрать ветку). Готовый файл — в разделе Artifacts запуска. Ключ Groq берётся из секрета `GROQ_API_KEY`.

## Музыка: разметка и второе приложение «Музыка»

- **Разметка.** Скажи «проанализируй мою музыку» (или кнопка «Разметить» в приложении «Музыка»). Модель определяет жанр, настроение (энергичная, спокойная, весёлая, грустная, романтичная, танцевальная, для фона, мощная) и энергичность 1–5 для каждой песни; жанр из тегов файла подсказывается модели. Идёт в фоне, прогресс в уведомлении, теги хранятся в `music_tags.json`.
- **По голосу.** «Включи спокойную музыку», «поставь что-нибудь энергичное», «музыку для работы», «включи рок/джаз/рэп», «как идёт разметка», «выгрузи список песен» (CSV `songs.csv` в Исходящие: исполнитель, название, альбом, жанр, настроение, энергия).
- **Приложение «Музыка»** — отдельный значок на экране. Вкладки: Треки, Настроение, Жанры, Исполнители, Плейлисты; поиск, мини-плеер, полноэкранный плеер (обложка, перемотка, перемешивание, повтор, очередь, «Ещё такое», таймер сна), меню песни (следующей, в очередь, в плейлист, характеристики). «Открой музыку» в ассистенте открывает его.

### Музыка, часть 2: разметка сама, таблица, лайки, папки

- **Таблица `Assistant/Музыка.xlsx`.** Приложение создаёт её само и обновляет при каждой разметке: исполнитель, название, альбом, жанр, настроение, энергичность, темп, описание, уверенность, пометка, «Нравится», «Папки», «Источник». Она переживает переустановку: при первом запуске «Музыка» читает её и размечает только то, чего там нет. Правки в Excel подхватываются при запуске. Свою готовую таблицу (например, `songs_by_mood.xlsx`) можно положить во «Входящие» и сказать «импортируй таблицу музыки».
- **Разметка сама.** При первом открытии «Музыки» (и после переустановки) в фоне идёт разметка пачками через модель Groq. Поиск в интернете не используется, чтобы не тратить дневной лимит. Если лимит кончился, разметка останавливается и продолжится позже. Ход виден в уведомлении, в конце приходит уведомление «Музыка размечена».
- **Разметка через другой ИИ.** Меню ⋮ → «Подготовить для другого ИИ» (или «подготовь музыку для другого ИИ») создаёт в `Исходящие/Музыка для ИИ` файлы-части по 100 песен с готовой инструкцией. Скопируй часть в ChatGPT, Gemini или Claude, скопируй его ответ и в «Музыке» нажми ⋮ → «Вставить ответ другого ИИ» (понимает CSV и таблицы markdown). Либо сохрани ответ как csv во «Входящие» и скажи «импортируй таблицу музыки».
- **Лайки.** ♥ в плеере, в меню песни и в редакторе; «поставь лайк», «не нравится эта песня», «включи любимое». Дизлайкнутые песни не попадают в подборки.
- **Редактор характеристик** (меню песни → «Изменить характеристики»): настроения галочками (можно несколько), жанр, энергичность 1–5, темп, описание, папки. Ручные правки ИИ больше не перезаписывает. Голосом: «эта песня грустная».
- **Папки** («Для бега», «Для прогулки») и плейлисты — одно и то же: создавать, переименовывать, удалять, добавлять и убирать песни, перекладывать между папками, в том числе голосом («убери эту песню из бега и добавь в прогулку»).
- **Сортировка:** по названию, исполнителю, дате добавления (новые/старые), любимые сверху.

## Дизайн, голос и надёжность (ветка polish)
- Чат: светлая/тёмная тема по системе, пузыри, анимация «думает», блоки кода с кнопкой «Копировать», копирование сообщений, подсказки в пустом чате.
- Озвучка: выбор голоса и скорости (меню чатов → «Голос и скорость озвучки»), паузы в речи, код не зачитывается.
- Голосовой ввод: ждёт паузу 1,8 с, перед записью останавливает озвучку.
- Wi-Fi/Bluetooth/режим полёта/геолокация/экономия заряда: состояние берётся из системы, после нажатия проверяется результат, при неудаче нажатие повторяется.

## Универсальность и музыка (ветка polish)
- В коде нет личных данных: имя и город приложение запоминает по просьбе («мой город — Астана», «меня зовут Анна»), язык, страна, валюта, единицы, 12/24 часа, модель телефона и доступные функции определяются само.
- Погода берётся из Open-Meteo без ИИ; без заданного города город угадывается по часовому поясу с предупреждением.
- Импорт разметки от другого ИИ: xlsx (все листы), csv, tsv, txt, md; заголовки по-русски и по-английски; «Исполнитель - Песня» в одной колонке; нечёткое сопоставление названий; можно выбрать файл в «Музыке» (⋮ → «Выбрать файл с разметкой»).
- Повторная разметка: «разметь музыку заново», «повтори неопознанные»; ручные правки и оценки сохраняются.
- Сердечко в уведомлении плеера, новый дизайн «Музыки».

## Универсальность и «Музыка» (ветка polish)
- В коде нет личных данных: имя и город запоминаются командами «меня зовут…», «мой город — …»; язык, страна, валюта, единицы, 12/24 часа и возможности телефона определяются самим устройством (DeviceInfo → PromptContext).
- Импорт разметки от другого ИИ: xlsx (все листы), csv, tsv, txt, md; заголовки по-русски и по-английски; «Исполнитель - Песня» в одной колонке; нечёткое сопоставление названий; файл можно выбрать вручную (меню ⋮ в «Музыке»).
- Повторная разметка: «разметь музыку заново», «повтори неопознанные»; ручные правки и оценки сохраняются.
- Сердечко в шторке (уведомление плеера и экран блокировки), новый дизайн списка, плеера и мини-плеера.
